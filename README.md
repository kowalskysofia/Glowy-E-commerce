Nombre del proyecto:
Glowy – E-commerce

Descripción breve:
Glowy es un ecommerce de productos de skincare desarrollado con React. Permite explorar productos, gestionar un carrito de compras y administrar productos y usuarios.

Tecnologías utilizadas:
HTML5: estructura del contenido.
CSS3: estilos y adaptación a distintos dispositivos.
JavaScript: lógica e interactividad de la aplicación.
React: desarrollo de la interfaz mediante componentes reutilizables.
Vite: herramienta de desarrollo y compilación del proyecto.
React Router: navegación entre páginas de la aplicación.
Axios: realización de solicitudes HTTP para obtener y gestionar datos.
React Hook Form: gestión y validación de formularios.
SweetAlert2: visualización de alertas y mensajes de confirmación.
Font Awesome: iconos utilizados en la interfaz.
MockAPI: servicio externo utilizado como API para almacenar y gestionar productos y usuarios.
Git y GitHub: control de versiones y almacenamiento del código fuente.

Pasos para clonar e instalar:
git clone https://github.com/tu-usuario/ecommerce-react
cd ecommerce-react
npm install
npm run dev
